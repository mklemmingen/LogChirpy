\section{Tutorial Feature}

The tutorial begins with a video that serves as an advertisement for the app.

Subtitles are provided in all six supported languages.

When the user clicks "Next", they are guided through the core functionalities of the app using swipeable screens that explains how to use the app, each accompanied by an animation.

The tutorial covers how to sign up, why the app uses two cameras, how to record audio, and how to save recordings to the archive.

It was implemented with `react-native-swiper`.


\section{Quiz Feature}

The quiz consists of three questions with different types:

The first question shows four images selected at random. 

The user has only one chance to choose one, and their points are saved to determine later whether they passed or not.

The second question includes a text input field where the user can enter the bird’s region.

The third question is a simple yes/no question.

At the end, the user receives their result (with an animation) 

and can choose either to restart the quiz or return to the home screen.
