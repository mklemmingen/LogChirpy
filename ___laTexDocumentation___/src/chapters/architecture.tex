\section{Overview}

LogChirpy is built on React Native with Expo SDK 52, targeting Android (API 29+)
and iOS.
Three functionally independent service pillars share a common navigation shell
and theme system (Figure~\ref{fig:arch}).

\section{Audio Classification Pipeline}

The audio pipeline implements BirdNET v2.4~\cite{BirdNET2021} through two
sequential TFLite models (Figure~\ref{fig:audio_pipeline}).

\textbf{Pre-processing.}
Raw audio is captured at 48\,kHz, mono; a bandpass filter (150--15\,000\,Hz)
attenuates wind and handling noise; amplitude is normalised to $[-1, 1]$.
A sliding 3-second window with 50\,\% overlap feeds inference at configurable
cadence.

\textbf{Acoustic model} (\texttt{BirdNET\_GLOBAL\_6K\_V2.4\_Model\_FP32.tflite}):
input tensor $\mathbb{R}^{1 \times 144\,000}$ (3\,s $\times$ 48\,kHz);
output sigmoid logits over 6,522 species.

\textbf{Metadata model} (\texttt{BirdNET\_GLOBAL\_6K\_V2.4\_MData\_Model\_FP16.tflite}):
input $\mathbb{R}^{3}$ = [\textit{latitude, longitude, week-cosine}];
output geographic prior over 6,522 species.
When GPS is available, blended scores are computed as:
\begin{equation}
  p_{\text{blend}} = p_{\text{audio}} \cdot (0.7 + 0.3 \cdot p_{\text{geo}})
  \label{eq:blend}
\end{equation}
The 0.3 meta-influence weight follows the whoBIRD reference implementation~\cite{WhoBird2023}.

\section{Image Classification Pipeline}

Camera-based identification uses a two-stage approach to control false positives.

\textbf{Stage 1 — Detection gate.}
SSD MobileNet V1 (via MLKit) runs at a configurable duty cycle on camera frames
compressed to JPEG quality 0.3.
Frames where the highest bird-class score falls below a user-adjustable threshold
are discarded, reducing wasted classifier calls.

\textbf{Stage 2 — Species classification.}
\texttt{bird\_classifier\_metadata.tflite} (MobileNetV2~\cite{Sandler2018})
takes a $224 \times 224$ RGB tensor normalised to $[-1, 1]$ and outputs logits
over 400 species.
Softmax probabilities above 0.05 are surfaced to the user with a confidence bar.

\textbf{Sequential pipeline.}
Early development revealed that concurrent audio recording and camera processing
caused \texttt{MediaRecorder} file-lock conflicts on Android.
\texttt{unifiedMLPipelineService.ts} enforces a strict image-then-audio sequencing;
this eliminated all file-stability errors and reduced peak memory consumption.

\section{BirDex Encyclopedia}

BirDex stores the complete Clements 2024 checklist~\cite{Clements2024} in an
on-device SQLite database (schema: Table~\ref{tab:birdex_schema}).
All 33,241 species carry translations in six languages generated by an automated
pipeline (DeepL $\rightarrow$ Google Translate $\rightarrow$ GPT-4 fallback)
and spot-checked by family.
Reference images (9,331 WebP files, $\sim$50\,kB mean) are fetched from Wikimedia
Commons at first launch and cached locally, organised by Clements genus.
