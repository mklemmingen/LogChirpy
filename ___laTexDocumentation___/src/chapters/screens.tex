\section{Feature Screens}

\subsection{Logging Features}
The logging section offers various methods to record bird observations. Users can choose between manual entry, audio recording, photo-based identification, and AI-assisted automatic identification. This multi-modal approach ensures accurate bird species identification regardless of the observation conditions or user expertise level.

Key aspects of the logging system:
\begin{itemize}
    \item \textbf{Multiple Input Methods}: Choose between manual, audio, and photo logging
    \item \textbf{AI Assistance}: Advanced machine learning for species identification
    \item \textbf{Location Integration}: Automatic GPS tagging of observations
    \item \textbf{Offline Capability}: Full functionality without internet connection
    \item \textbf{Data Validation}: Accuracy checks for species identification
\end{itemize}

\subsection{Account Features}
The account section provides user authentication for syncing bird logs across devices. All other app features work completely offline without requiring login. This design ensures maximum accessibility while offering optional cloud synchronization for users who want to access their bird spotting data on multiple devices.

    \centering

Key aspects of the account system:
\begin{itemize}
    \item \textbf{Optional Authentication}: Login is only required for cloud sync
    \item \textbf{Offline-First}: All features work without authentication, except sync
    \item \textbf{Sync Management}: Control when and how data syncs
    \item \textbf{Data Privacy}: Encrypted cloud storage when syncing
    \item \textbf{Cross-Device Access}: Access logs on multiple devices when logged in
\end{itemize}
